The Lite network trades playing strength for a smaller browser download (~7 MB).
This integration uses Skill Level 20, UCI_LimitStrength false, Hash 32 MB,
and go movetime 8000 in a dedicated Worker. No Elo rating is claimed.
The engine loads only when an Extreme computer move is needed.
